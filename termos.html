Horst Ads

Horst Ads produz vídeos curtos de divulgação de produtos para lojas online e os publica nas contas do próprio dono, Kevin Horst. O app Horst Ads usa a API do TikTok apenas para enviar esses vídeos como rascunho para a conta TikTok do dono, que revisa e publica pelo aplicativo.

Horst Ads creates short product videos and uses the TikTok Content Posting API only to upload them as drafts to the owner's own TikTok account, where the owner reviews and publishes them.

Termos de uso

Última atualização: 17 de outubro de 2026

1. O serviço

O Horst Ads é uma ferramenta interna de uso pessoal. Ele cria vídeos de produtos e, com a autorização do usuário pelo login do TikTok, envia esses vídeos para a caixa de rascunhos da conta TikTok do usuário.

2. Quem pode usar

O serviço é usado apenas pelo dono do Horst Ads em suas próprias contas. Não é oferecido ao público.

3. Responsabilidades

O usuário revisa cada rascunho antes de publicar e é responsável pelo conteúdo que publica, seguindo os Termos de Serviço e as Diretrizes da Comunidade do TikTok.

4. Cancelamento

O usuário pode retirar a autorização a qualquer momento nas configurações do TikTok, em Segurança e Apps conectados.

5. Contato

Dúvidas sobre estes termos: pelo perfil Horst Ads na Shopee.

Política de privacidade

Última atualização: 17 de outubro de 2026

Dados que recebemos do TikTok

  • Informações básicas do perfil (nome de exibição e identificador da conta), para saber em qual conta enviar os rascunhos.
  • O token de acesso que o TikTok entrega após o login, usado só para enviar vídeos.

Como usamos

Usamos esses dados apenas para enviar vídeos de produtos à conta do próprio usuário. Não vendemos, não compartilhamos e não usamos esses dados para anúncios.

Armazenamento

O token fica guardado como segredo protegido do ambiente de produção e nunca é publicado. Os vídeos enviados ficam na conta TikTok do usuário.

Exclusão

Ao retirar a autorização nas configurações do TikTok, o token deixa de funcionar e é apagado do nosso ambiente.

Horst Ads only receives basic profile info and an access token to upload drafts to the user's own account. Data is never sold or shared. Revoking access in TikTok settings ends it.
